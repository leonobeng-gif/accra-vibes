# Accra Vibes 🇬🇭

Stylized 3D open-world life-simulation prototype set in an Osu-inspired Accra neighbourhood.

## Play
Visit the deployed website. Walk with WASD or arrow keys, interact with E, and toggle driving with F after purchasing a car. Mobile touch controls are provided.

Alpha 0.2 includes a GH₵ wallet, delivery missions, a vehicle, simple property and kiosk ownership, ambient streets, and local browser saving.

**Note:** The city is currently a fictional blockout inspired by Osu, not yet a precise OpenStreetMap-based reconstruction.

This is a prototype for playtesting, not a production-ready commercial game.
